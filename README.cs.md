# SunamoEssential

## Short description

Balíček SunamoEssential je základní knihovna sady Sunamo pro .NET. Obsahuje základní pomocné třídy (např. CleanUp, SharedAlgorithms, VpsHelperSunamo, WebApp, argumenty událostí) používané ostatními balíčky. K balíčku patří testovací projekt a Runner pro lokální spuštění.
